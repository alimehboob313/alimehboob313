## 🚀 Featured Projects

### 🤖 [SneakDoc RAG Chatbot](https://github.com/alimehboob313/sneakdoc-chatbot)
Customer support chatbot for a sneaker-care e-commerce brand, built from scratch. FastAPI + ChromaDB + Gemini embeddings, deployed on Render with a JS widget embedded via WordPress. 51 semantic chunks across 24 products, with session-based conversation memory.

### 🔍 [Website Technical Audit (n8n)](https://github.com/alimehboob313/-n8n-website-technical-audit)
Automated technical SEO/performance audit workflow — reads sites from Google Sheets, runs PageSpeed + structural audits, and generates two styled PDF reports (technical + plain-English outreach) via PDFShift and Gemini.

### 🧩 [SEO Keyword Gap Finder (n8n)](https://github.com/alimehboob313/n8n-seo-keyword-gap-finder)
Finds untapped content opportunities by comparing Google Autocomplete suggestions against existing site pages, then auto-generates blog briefs with Groq for any real content gaps found.

### 📇 [Virginia Business Lead Finder (n8n)](https://github.com/alimehboob313/n8n-virginia-lead-finder)
Lead-gen pipeline using the Google Places API to discover and qualify local businesses, scrape contact emails, and log AI-summarized leads to Google Sheets — ready for outreach.
